1. PASOS DEL DESARROLLO
-----------------------
1) Investigamos los precios reales de octubre 2026:
   - Gasoil regular: RD$270.80 por galón (MICM, semana 24-30 de octubre).
   - Metro y Teleférico de Santo Domingo: RD$20; tarifa integrada: RD$35.
   - Precio conocido para calibrar: Santiago -> Santo Domingo en guagua = RD$450.
2) Creamos el proyecto con React + Vite y lo pusimos en Git.
3) Cargamos 28 ciudades con su latitud y longitud (src/data/ciudades.js).
4) Programamos los cálculos: distancia (Haversine x 1.22), pasaje
   (base + precio por km) y ajuste por el precio del gasoil (src/logic/calculos.js).
5) Hicimos la pestaña "Entre ciudades": origen, destino, botón para intercambiar,
   pasajeros, ida y vuelta, y tarjetas con precio y tiempo de cada transporte.
6) Hicimos la pestaña "En la ciudad": gasto por viaje, día, semana y mes,
   con gráfica de barras para comparar transportes.
7) Agregamos la barra "¿y si sube el gasoil?" que recalcula todos los pasajes.
8) Agregamos el historial de rutas y guardamos las preferencias con localStorage
   usando un hook propio (usePersistente).
9) Agregamos modo oscuro, animaciones CSS y diseño para celular.
10) Probamos todo en el navegador y tomamos las capturas.
11) Dejamos listo GitHub Actions (.github/workflows/deploy.yml) para publicarlo
    en GitHub Pages; la publicación la hace otro integrante del grupo.
